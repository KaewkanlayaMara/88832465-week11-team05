## เกี่ยวกับงาน

ทีม 05 ใช้ repository นี้สำหรับจัดเก็บผลงานและทำงานร่วมกันด้วย Git และ GitHub

**หัวข้อหรือชื่อชิ้นงาน:** เว็บไซต์แนะนำตัว พีรวิชญ์ ชูแสง  
**รายละเอียด:** เว็บแนะนำตัวแบบ static สำหรับนำเสนอข้อมูลนิสิตคณะวิทยาการสารสนเทศ

## การทำงานร่วมกัน

1. สร้าง branch สำหรับงานที่รับผิดชอบ
2. แก้ไขงานและ commit พร้อมข้อความที่อธิบายสิ่งที่เปลี่ยน
3. push branch ขึ้น GitHub
4. เปิด Pull Request ให้เพื่อนร่วมทีมตรวจ ก่อนรวมงานเข้า `main`
5. ตรวจสอบผลหลังรวมงานว่าข้อมูลและไฟล์ของสมาชิกคนอื่นยังอยู่ครบ

## วิธีเปิดดูหรือใช้งานผลงาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง หรือรันคำสั่งด้านล่างจากโฟลเดอร์โปรเจกต์เพื่อเปิดผ่าน local server

```bash
python3 -m http.server 4173
```

จากนั้นเปิด `http://localhost:4173` ในเว็บเบราว์เซอร์
