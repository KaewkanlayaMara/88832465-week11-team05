## การทำงานร่วมกัน

1. สร้าง branch สำหรับงานที่รับผิดชอบ
2. แก้ไขงานและ commit พร้อมข้อความที่อธิบายสิ่งที่เปลี่ยน
3. push branch ขึ้น GitHub
4. เปิด Pull Request ให้เพื่อนร่วมทีมตรวจ ก่อนรวมงานเข้า `main`
5. ตรวจสอบผลหลังรวมงานว่าข้อมูลและไฟล์ของสมาชิกคนอื่นยังอยู่ครบ
